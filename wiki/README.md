# Wiki sources

These Markdown files are the pages of the project's GitHub wiki. The file name is the page name, and `_Sidebar.md` / `_Footer.md` are the wiki's sidebar and footer.

Edit them here, in the main repository, so they are reviewed with the code. To publish them, run **Actions → Wiki → Run workflow**: it replaces the wiki content with this folder (this README is skipped).

One-time setup: enable the wiki in **Settings → General → Features → Wikis** and create any first page in the web UI. GitHub only creates the wiki's git repository after that.

Links between pages use the page name without `.md`, e.g. `[Callbacks](Callbacks)`.
